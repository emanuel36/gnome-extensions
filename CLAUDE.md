# gnome-extensions

Monorepo of GNOME Shell extensions imported from upstream with `git subtree --squash` and
maintained as my own code (not forks). Each extension lives in `extensions/<name>/`. The
README table is the source of truth for where each one came from; update it whenever a
subtree is pulled again.

Start-of-project context (findings, local patches, decisions so far):
`docs/superpowers/2026-10-22-contexto-inicial.md`. Designs go in `docs/superpowers/specs/`.

## Target environment

- Ubuntu 24.04, GNOME Shell 46, X11 session. Everything must run on GNOME 46.
- The copies that actually run are in `~/.local/share/gnome-shell/extensions/`, installed
  from extensions.gnome.org (EGO). They are separate from this repo, and some were patched
  in place (see the context doc).
- GNOME 45+ caches extension modules: disable/enable does not reload changed JS. Restart the
  shell (X11: Alt+F2, `r`) or log out.
- Shell/extension logs: `journalctl --user -b | rg -i <name>`.

## Git

- Identity is set in this repo's local config (emanuel36, GitHub noreply email). Don't change it.
- `origin` uses the SSH host alias `github.com-emanuel36` (key `~/.ssh/id_emanuel36`).
  The GitHub repo does not exist yet. Never push unless asked.
- `git subtree add/pull -m` keeps only the last `-m`: pass a single message with embedded
  newlines.

## Licensing

- Keep each extension's upstream license file and copyright notices.
- GPL-3.0 files that get modified must carry a notice saying they were changed, with the date.
- Code combined from GPL-3.0 and MIT extensions must be released as GPL-3.0.

## Gotchas

- An extension whose `metadata.json` keeps the upstream UUID and the EGO
  `"_generated": "Generated by SweetTooth..."` key gets auto-updated by GNOME from EGO,
  overwriting local code.
